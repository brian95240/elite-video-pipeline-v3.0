# Elite Video Pipeline v3.2 - Cloud Render Extension

**On-Demand GPU Rendering with Cost Arbitration and Confirmation Handshake**

---

## Overview

Version 3.2 introduces the **Cloud Render Extension**, a natural evolution of the SOTA Sentinel Protocol that enables on-demand GPU rendering at the lowest cost while maintaining vertex quality. The system decouples creative work (done locally for free) from pixel generation (done on cloud GPUs only when explicitly confirmed), ensuring you never pay for rendering until the very last second.

---

## Architecture

### The Print Shop Broker Analogy

Think of v3.2 as a **Print Shop Broker** added to a digital design firm:

- The **Design Firm (Local System)** does all creative work (layout, colors, cinematography) on screen for free
- When the client says "Print 1000 copies" (**Render Intent**), the **Broker (GPU Render Broker)** instantly calls 50 print shops to find the one with the highest quality but the lowest spot price for that hour
- The Broker presents the quote to the client. Only after the client signs the check (**Confirmation**) does the Broker send the files to the printer

This ensures you never pay for a rendering press until you're ready.

## Key Components

### 1. Render Intent Detection (`prompt_parser.py`)

The MicroChunker now detects a third tensor: **RenderIntent**

**Trigger Keywords:**
- `render`, `export`, `final cut`, `final render`, `output`
- `generate video`, `create video`, `make video`, `produce`
- `compile`, `finish`, `finalize`, `deliver`

**Detected Parameters:**
- **Render Type:** `preview`, `final`, `export`
- **Resolution:** `720p`, `1080p`, `4k`, `8k`
- **Quality:** `preview`, `high`, `production`
- **Output Format:** `mp4`, `png_sequence`, `exr_sequence`
- **FPS:** 24, 30, 60
- **Frame Range:** `frames 1-100`, `frame 10 to 50`

**Example:**
```python
from prompt_parser import create_parser

parser = create_parser()
aesthetic, kinetic, render_intent = parser.parse_split_stream(
    "Render this scene in 4k at 24fps for final production"
)

if render_intent.is_render_request:
    print(f"Render Type: {render_intent.render_type}")  # "final"
    print(f"Resolution: {render_intent.resolution}")    # "4k"
    print(f"Quality: {render_intent.quality}")          # "production"
```

### 2. GPU Render Broker (`gpu_render_broker.py`)

Cost arbitration engine that selects the best GPU provider using vertex logic.

**Provider Registry:**
- **Hetzner Cloud GPU** (preferred - user's account)
- **Vast.ai** (lowest cost, variable availability)
- **Tensordock** (good balance)
- **RunPod** (reliable mid-tier)
- **Lambda Labs** (premium option)

**Vertex Scoring Algorithm:**
```python
# Quality score (VRAM + uptime)
vram_score = min(vram_gb / 48.0, 1.0)
quality_score = (vram_score + uptime_sla) / 2.0

# Cost score (inverse of price)
cost_score = baseline_price / spot_price

# Combined vertex score (60% quality, 40% cost)
vertex_score = (quality_score * 0.6) + (cost_score * 0.4)
```

**Penalties:**
- Below quality threshold: 50% penalty
- Exceeds cost ratio: 30% penalty

**Environment Variables:**
- `VERTEX_QUALITY_THRESHOLD`: Minimum quality (default: 0.7)
- `VERTEX_COST_RATIO_MAX`: Maximum cost ratio (default: 2.0x)

**Example:**
```python
from gpu_render_broker import create_gpu_broker

broker = create_gpu_broker()
broker.load_providers_from_manifest()

best_provider, estimated_cost = broker.select_best_provider(render_intent)

print(f"Provider: {best_provider.name}")
print(f"GPU: {best_provider.gpu_model}")
print(f"Cost: ${estimated_cost:.3f}")
```

### 3. Confirmation Handshake (`api_server.py`)

Pre-flight estimate with explicit user confirmation to prevent runaway costs.

**Workflow:**

1. **User submits render request:**
   ```bash
   POST /render/estimate
   {
     "prompt": "Render this scene in 4k at 24fps"
   }
   ```

2. **System returns 202 Accepted with estimate:**
   ```json
   {
     "status": "pending_confirmation",
     "job_id": "uuid-here",
     "message": "Ready to render on Hetzner Cloud GPU. Cost: $5.600. Confirm?",
     "provider": {
       "name": "Hetzner Cloud GPU",
       "gpu_model": "NVIDIA RTX 4090",
       "vram_gb": 24,
       "spot_price_per_hour": 0.35
     },
     "estimated_cost_usd": 5.600,
     "vertex_confidence": 0.95,
     "confirmation_endpoint": "/render/confirm/{job_id}",
     "expires_in_seconds": 300
   }
   ```

3. **User confirms:**
   ```bash
   POST /render/confirm/{job_id}
   ```

4. **System dispatches to cloud GPU:**
   ```json
   {
     "status": "confirmed",
     "job_id": "uuid-here",
     "message": "Render job confirmed and queued for execution",
     "tracking_endpoint": "/render/status/{job_id}"
   }
   ```

5. **User tracks progress:**
   ```bash
   GET /render/status/{job_id}
   ```

### 4. Cloud Render Executor (`cloud_render_executor.py`)

Asynchronous cloud GPU rendering with cascading manifest compilation.

**Features:**
- Compiles render manifest from scene data
- Generates Blender Python script
- Generates FFmpeg commands
- Dispatches to selected provider
- Tracks job status

**Supported Providers:**
- Hetzner Cloud GPU (preferred)
- Vast.ai
- Tensordock
- RunPod
- Generic fallback

**Example:**
```python
from cloud_render_executor import create_cloud_executor

executor = create_cloud_executor()

job = executor.dispatch_render_job(
    job_id="job-001",
    provider=best_provider,
    render_intent=render_intent,
    scene_manifest=scene_data
)

print(f"Job Status: {job.status}")
print(f"Manifest: {job.render_manifest_path}")
print(f"Output: {job.output_path}")
```

## API Endpoints

### `POST /render/estimate`

Get pre-flight render cost estimate WITHOUT starting render.

**Request:**
```json
{
  "prompt": "Render this scene in 4k at 24fps",
  "scene_data": {}  // Optional
}
```

**Response:** `202 Accepted`
```json
{
  "status": "pending_confirmation",
  "job_id": "uuid",
  "message": "Ready to render on [Provider]. Cost: $X.XXX. Confirm?",
  "render_intent": {...},
  "provider": {...},
  "estimated_cost_usd": 5.600,
  "vertex_confidence": 0.95,
  "confirmation_endpoint": "/render/confirm/{job_id}",
  "expires_in_seconds": 300
}
```

## Cost Analysis

### Render Cost Estimates

| Resolution | Quality | Minutes/Frame | Cost/Minute | 10s @ 24fps Cost |
|------------|---------|---------------|-------------|------------------|
| 720p | Preview | 0.15 | $0.003 | $0.01 |
| 1080p | Preview | 0.15 | $0.003 | $0.01 |
| 1080p | Production | 0.5 | $0.005 | $0.06 |
| 4K | Preview | 0.6 | $0.012 | $0.17 |
| 4K | Production | 2.0 | $0.020 | $0.96 |
| 8K | Production | 8.0 | $0.080 | $7.68 |

### Cost Optimization

**Traditional Approach:**
- All creative work + rendering done on cloud GPU
- Cost: $0.35/hour × 24 hours = $8.40/day
- **Annual cost:** $3,066

**v3.2 Approach:**
- Creative work done locally (free)
- Rendering only when confirmed
- Cost: $0.35/hour × 2 hours = $0.70/day (assuming 2 hours rendering)
- **Annual cost:** $255

**Savings:** $2,811/year (92% reduction)
